# Enhanced UNC Benchmark

**No spoof, just proof.**

Enhanced UNC Benchmark (eUNC) is a behavior-based Roblox executor capability benchmark designed to test whether executor functions behave as expected.

Rather than relying exclusively on function presence, eUNC aims to evaluate actual behavior and report the results transparently.

## Philosophy

eUNC follows three principles:

- **Behavior over presence:** A function existing does not automatically prove that it works correctly.
- **Transparency:** Results should accurately represent observed behavior.
- **No spoofing:** Tests should not be modified to produce artificial success.

## Important Disclaimer

eUNC is a capability benchmark, not a security certification.

A high score does not guarantee that an executor is safe, secure, trustworthy, or free from malicious behavior.

Likewise, a low score does not automatically mean an executor is malicious or unusable.

Results should be interpreted alongside the actual test behavior and execution environment.
